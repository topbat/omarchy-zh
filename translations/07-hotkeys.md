# 快捷键

使用 `Super + K` 查看主要键盘绑定（Tmux 绑定是 `Super + Alt + K`，Herdr 绑定是 `Super + Ctrl + K`）。

## 导航

| 快捷键 | 功能 |
| --- | --- |
| `Super + Space` | Omarchy 菜单（应用及其他功能） |
| `Super + Alt + Space` | 应用菜单 |
| `Super + Escape` | 系统菜单（挂起、重启等） |
| `Super + Ctrl + L` | 锁定电脑 |
| `Super + W` 或 `Super + Q` | 关闭窗口 |
| `Ctrl + Alt + Del` | 关闭所有窗口 |
| `Super + T` | 在平铺/浮动之间切换窗口 |
| `Super + J` | 切换窗口排列方向（水平/垂直） |
| `Super + O` | 将窗口切换为固定浮动窗口 |
| `Super + L` | 在 dwindle 与滚动布局之间切换 |
| `Super + P` | 切换伪窗口样式（自然/拉伸） |
| `Super + F` | 全屏 |
| `Super + Alt + F` | 全宽 |
| `Super + Ctrl + F` | 在窗口内部全屏 |
| `Super + 1/2/3/4` | 跳转到指定工作区 |
| `Super + Tab` | 下一个工作区 |
| `Super + Shift + Tab` | 上一个工作区 |
| `Super + Ctrl + Tab` | 返回之前的工作区 |
| `Super + Shift + 1/2/3/4` | 将窗口移动到指定工作区 |
| `Super + Shift + Alt + 1/2/3/4` | 将窗口移动到工作区但不跟随切换 |
| `Super + S` / `Super + Grave` | 切换 Scratchpad |
| `Super + Alt + S` / `Super + Shift + Grave` | 将窗口移动到 Scratchpad |
| `Super + Shift + Alt + Arrows` | 将工作区移动到对应方向的显示器 |
| `Super + Arrow` | 将焦点移动到箭头方向的窗口 |
| `Super + Shift + Arrow` | 与箭头方向的另一个窗口交换位置 |
| `Super + Minus` | 向左扩大窗口 |
| `Super + Equal` | 向左缩小窗口 |
| `Super + Shift + Minus` | 向上缩小窗口 |
| `Super + Shift + Equal` | 向下扩大窗口 |
| `Super + Alt + Minus/Equal` | 使用更小步长调整大小 |
| `Super + Ctrl + Minus/Equal` | 使用更大步长调整大小 |
| `Super + Alt + Home` | 保存窗口宽度 |
| `Super + Home` | 恢复保存的窗口宽度 |
| `Super + Left Mouse` | 拖动窗口 |
| `Super + Right Mouse` | 调整窗口大小 |
| `Super + Scroll Wheel` | 浏览工作区 |
| `Super + G` | 切换窗口分组 |
| `Super + Alt + G` | 将窗口移出分组 |
| `Super + Alt + Tab` | 在分组内循环窗口 |
| `Super + Alt + Shift + Tab` | 反向循环分组内窗口 |
| `Super + Alt + 1/2/3/4/5` | 跳转到分组内指定窗口 |
| `Super + Alt + Arrow` | 将窗口按方向移入分组 |
| `Super + Ctrl + Left/Right` | 在平铺分组内切换窗口 |
| `Super + Ctrl + Z` | 放大屏幕（重复使用可继续放大） |
| `Super + Ctrl + Alt + Z` | 完全缩小屏幕 |
| `Super + /` | 向前切换显示器缩放选项 |
| `Super + Alt + /` | 向后切换显示器缩放选项 |
| `Alt + Tab` | 在当前工作区向前循环窗口 |
| `Alt + Shift + Tab` | 在当前工作区反向循环窗口 |
| `Ctrl + Alt + Tab` | 向前切换显示器焦点 |
| `Ctrl + Alt + Shift + Tab` | 反向切换显示器焦点 |

## 通用剪贴板

| 快捷键 | 功能 |
| --- | --- |
| `Super + C` | 复制 |
| `Super + X` | 剪切（终端中除外） |
| `Super + V` | 粘贴 |
| `Super + Ctrl + V` | 剪贴板管理器 |

通常在 Linux 中，终端需要使用 `Ctrl + Shift + C/V` 复制粘贴，而其他地方使用 `Ctrl + C/V`。Omarchy 的统一剪贴板快捷键在所有地方都能工作。

## 截图与录制

| 快捷键 | 功能 |
| --- | --- |
| `Super + Ctrl + C` | 截图菜单（适用于没有 PrintScr 键的键盘） |
| `Print Screen` | 截图 |
| `Alt + Print Screen` | 录屏 |
| `Super + Print Screen` | 取色器 |
| `Super + Ctrl + Print Screen` | 提取文字到剪贴板 |
| `Super + Alt + [` | 录制时缩小摄像头叠加层 |
| `Super + Alt + ]` | 录制时放大摄像头叠加层 |
| `Alt + Shift + L` | 从 Web 应用或 Chromium 复制当前 URL |
| `Alt + Shift + D` | 将当前页面视频下载到 `~/Videos` |
| `Super + Ctrl + X` | 开始/停止听写（需要 _Install > AI > Dictation_） |
| `F9` | 按住说话听写（需要 _Install > AI > Dictation_） |

录屏时，第一次按下快捷键会询问要录制哪些音频，再次按下即可停止。详见[截图与录屏](12-screenshots-recording.md)。所有截图选项也可以在 Omarchy 菜单（`Super + Space`）的 _Trigger > Capture_ 下访问。

## Tmux

前缀键是 `Ctrl + Space`（`Ctrl + B` 也有效）。可以在 `~/.config/tmux/tmux.conf` 中更改这些绑定。

### 窗格

| 快捷键 | 功能 |
| --- | --- |
| `Prefix + v` | 在旁边拆分窗格（垂直） |
| `Prefix + h` | 在下方拆分窗格（水平） |
| `Prefix + x` | 关闭窗格 |
| `Prefix + z` | 切换窗格缩放（全屏） |
| `Alt + Enter` | 在下方拆分窗格（无需前缀） |
| `Alt + Shift + Enter` | 在旁边拆分窗格（无需前缀） |
| `Alt + Escape` | 关闭窗格（无需前缀） |
| `Ctrl + Alt + Arrows` | 在窗格之间移动 |
| `Ctrl + Alt + Shift + Arrows` | 调整窗格大小 |

### 窗口

| 快捷键 | 功能 |
| --- | --- |
| `Prefix + c` | 新建窗口 |
| `Prefix + k` | 关闭窗口 |
| `Prefix + r` | 重命名窗口 |
| `Alt + 1-9` | 转到指定窗口 |
| `Alt + Arrow Left/Right` | 在窗口之间移动 |
| `Alt + Shift + Arrow Left/Right` | 向左/向右移动窗口 |

### 会话

| 快捷键 | 功能 |
| --- | --- |
| `Prefix + C` | 新建会话 |
| `Prefix + K` | 关闭会话 |
| `Prefix + R` | 重命名会话 |
| `Prefix + N` | 下一个会话 |
| `Prefix + P` | 上一个会话 |
| `Alt + Arrow Up/Down` | 在会话之间移动 |
| `Prefix + s` | 列出会话 |
| `Prefix + d` | 从会话中分离 |

### 复制模式（vi 风格）

| 快捷键 | 功能 |
| --- | --- |
| `Prefix + [` | 进入复制模式 |
| `v` | 开始选择（复制模式中） |
| `y` | 复制选择内容（复制模式中） |

### 常规

| 快捷键 | 功能 |
| --- | --- |
| `Prefix + q` | 重新加载配置 |
| `Prefix + ?` | 显示 Tmux 快捷键 |
| `Prefix + :` | 命令提示符 |

### Tmux 布局功能

这些功能必须在 Tmux 会话内运行。

| 命令 | 功能 |
| --- | --- |
| `tdl <ai> [<second_ai>]` | 创建包含编辑器、AI 和终端的开发布局 |
| `tdlm <ai> [<second_ai>]` | 为每个子目录创建开发布局 |
| `tsl <count> <command>` | 创建多窗格 swarm 布局 |
