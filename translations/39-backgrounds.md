# 背景

每个主题都自带一组背景，你也可以在 `~/.config/omarchy/backgrounds/[theme]` 中添加自己的背景。比如，你想为 nord 主题添加一张背景图片，只需将文件放入 `~/.config/omarchy/backgrounds/nord`。

最简单的方式是前往 Omarchy 菜单中的 _Install > Style > Background_。这会打开存放该主题背景的文件夹。按下 `Super + Shift + F` 启动另一个文件管理器，找到你的背景并将其复制过去。现在，你就可以使用 `Super + Ctrl + Space` 在可选背景中切换，并看到这张背景了。

你可以在 https://github.com/dharmx/walls 找到大量精心挑选的精美背景集合。
