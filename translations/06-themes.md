# 主题

Omarchy 自带 22 个精心设计的主题。你可以在 Omarchy 菜单（`Super + Space`）中通过 _Style > Theme_ 选择主题，也可以使用 `Super + Ctrl + Shift + Space` 直接打开主题选择器。

每个主题都会统一设置桌面、终端、Neovim、活动监视器（btop）、Chromium 以及整个 Omarchy Shell，包括顶部栏、菜单、通知、OSD 和锁屏。对于 Obsidian，需要在应用内部通过 _Appearance > Themes_ 手动选择 Omarchy 主题。

每个主题还包含一组背景图片，可以使用 `Super + Ctrl + Space` 选择。

你可以在[额外主题页面](https://omarchy.org/themes/)找到更多主题，也可以[制作自己的主题](43-making-your-own-theme.md)。
