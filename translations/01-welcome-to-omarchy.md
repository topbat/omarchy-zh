# 欢迎使用 Omarchy！

Omarchy 是一个基于 [omakase](https://manuals.omamix.org/3/omacom/76/omakase-computing)、[Arch](https://archlinux.org/)、平铺窗口管理器 [Hyprland](https://hypr.land/) 和桌面构建工具 [Quickshell](https://quickshell.org/) 的 Linux 发行版。它预装了现代用户立即开始高效工作的常用工具，从 [Neovim](https://neovim.io/)、Chromium、[Obsidian](https://obsidian.md/) 和 LibreOffice，到 Kdenlive、OBS Studio，甚至复古 Winamp 风格的音乐播放器。

这并不只是一些预装软件的集合，而是一套围绕美感与生产力设计的完整系统。没有多余负担，只有一套经过明确取舍的工作环境。

Omarchy 不追求像 Windows 或 macOS 一样熟悉；它鼓励你拥抱 Linux，习惯终端，并尝试一种不同的电脑工作方式。关于这种美学和生产力理念，可以参阅 [相关说明](https://world.hey.com/dhh/beautiful-motivations-6fef7c73)。

让我们从基础开始。
