# 字体

Omarchy 默认使用 JetBrainsMono Nerd Font 作为终端和系统字体。

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

你可以通过 Omarchy 菜单（`Super + Space`）中的 _Style > Font_ 菜单进行更改。这会将等宽字体设置到所有地方：终端、状态栏，以及其他任何需要它的地方。

你可以通过 Omarchy 菜单中的 _Install > Style > Font_ 安装其他常用的编程字体：Cascadia Mono、Meslo LG Mono、Fira Code、Victor Code、Bitstream Vera Mono 和 Iosevka 都可以一键安装，并且提供 Nerd Font 版本，因此状态栏和终端中的字形能够继续正常工作。安装后，在 _Style > Font_ 下选中它即可。
