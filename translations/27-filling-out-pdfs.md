# 填写 PDF

Omarchy 附带一个简洁好用的 PDF 查看器，名为 Document Viewer。你只需双击 PDF 文件，就会由这个程序打开。

不过，只有已设置为表单的 PDF 才能用 Document Viewer 填写。如果需要填写尚未设置为表单的 PDF，或需要签署 PDF，则必须右键点击文件，选择 _Open With..._，然后选择 Xournal++。

Xournal++ 可以让你使用 T tool 在 PDF 的任意位置书写。如果需要签署文档，则需要一张签名图片；你可以使用 Image tool 插入这张签名图片并调整其大小。

填写完 PDF 后，使用 _File > Export as PDF_ 保存最终版本。
