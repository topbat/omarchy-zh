# Web 应用

你可以使用 Omarchy 菜单（`Super + Space`）中的 _Install > Web App_ 添加自己的 Web 应用。它会要求你提供应用名称、应用 URL；如果无法通过 favicon 获取图标，还会要求提供图标 URL。你可以在 [Dashboard Icons](https://dashboardicons.com) 上找到许多热门 Web 应用的精美 PNG 图标。

之后，可以通过应用启动器（`Super + Space`）访问它们，并使用美观的无边框 Web 应用窗口。

如果要移除某个 Web 应用，只需前往 Omarchy 菜单中的 _Remove > Web App_。

在使用 Web 应用快捷方式之前，最好先通过常规浏览器登录你的所有账户。这个轻量封装框架无法很好地配合 1Password，因此先直接登录会更容易。

这些 Web 应用的所有键盘快捷键都可以在 `~/.config/hypr/bindings.lua` 中更改。

在 Web 应用中时，可以使用 `Shift + Alt + L` 将当前 URL 复制到剪贴板。

默认情况下，Omarchy 已经附带一系列默认应用：

## HEY

[HEY](https://www.hey.com/) 是一项电子邮件和日历服务，对于厌倦了 Gmail、Outlook 或 Apple Mail 的用户来说，是一个很好的替代选择。它由 Omarchy 的发源公司 [37signals](https://37signals.com/) 打造。

可以使用 `Super + Shift + E` 启动 HEY Email，使用 `Super + Shift + Alt + E` 直接开始撰写新邮件，并使用 `Super + Shift + C` 启动 HEY Calendar。

## Basecamp

[Basecamp](https://basecamp.com/) 是一项项目管理服务，可帮助小型团队更快推进工作、取得更多进展。你不必再把 Trello、Slack、Asana、Notion 或其他各种工具东拼西凑，而是可以通过 Basecamp 在一个地方拥有所需的一切。它由 Omarchy 的发源公司 [37signals](https://37signals.com/) 打造。

可以使用应用启动器（`Super + Space`）启动 Basecamp。

## ChatGPT

[ChatGPT](https://chatgpt.com) 是全球最受欢迎的 AI 聊天机器人。

可以使用 `Super + Shift + A` 启动 ChatGPT。

## Grok

[Grok](https://grok.com) 是 xAI 的聊天机器人。

可以使用 `Super + Shift + Alt + A` 启动 Grok。

## WhatsApp

[WhatsApp](https://www.whatsapp.com/) 是全球最受欢迎的消息服务之一，其 Web 版本是 Linux 上的绝佳选择。

可以使用 `Super + Shift + Alt + G` 启动 WhatsApp。

## Google 应用

Google Messages、Google Photos、Google Maps 和 Google Contacts 也都作为 Web 应用包含在内。

可以使用 `Super + Shift + Ctrl + G` 启动 Google Messages，使用 `Super + Shift + P` 启动 Google Photos，并使用 `Super + Shift + S` 启动 Google Maps。Google Contacts 可通过应用启动器（`Super + Space`）访问。

## X

X 是新闻发生的地方。

可以使用 `Super + Shift + X` 启动 X，并使用 `Super + Shift + Alt + X` 直接开始撰写新帖子。

## YouTube

[YouTube](https://youtube.com/) 是全球最受欢迎的视频平台。

可以使用 `Super + Shift + Y` 启动 YouTube。

## Zoom

[Zoom](https://zoom.us/) 是美国使用最广泛的视频聊天系统。它在世界各地都能提供出色的连接，而且无需付费账户即可举行 40 分钟的会议。Omarchy 封装了 Zoom 的 Web 客户端，Zoom 会议链接会直接在其中打开。

使用应用启动器（`Super + Space`）启动 Zoom。

## Discord

[Discord](https://discord.com/) 是大多数游戏和开源社区聚集的地方，包括 [Omarchy 自己的社区](https://discord.gg/tXFUdasqhY)。

使用应用启动器（`Super + Space`）启动 Discord。
